# 🧭 Life Tracker App

# Transforme seus objetivos em ações diárias e acompanhe seu progresso sem perder a visão do todo.

# 

# Aplicativo pessoal de produtividade, metas, hábitos, finanças e evolução pessoal. Desenvolvido com Python e Streamlit.

# 

# 📌 Propósito

# O Life Tracker App ajuda a organizar a rotina e avançar em áreas importantes da vida em um só lugar. Conecta o que você quer alcançar — metas — com o que precisa fazer — tarefas, hábitos e compromissos — e mostra como está evoluindo ao longo do tempo.

# 

# Proposta de valor

# Transforme seus objetivos em ações diárias e acompanhe seu progresso sem perder a visão do todo.

# 

# 🎯 Público-alvo

# Pessoas que usam ferramentas demais para organizar a vida.

# Quem quer criar constância em hábitos e metas.

# Quem precisa equilibrar rotina, trabalho, saúde e finanças.

# Quem prefere acompanhar o próprio progresso, sem competição ou cobranças excessivas.

# ✨ Funcionalidades atuais

# 

# 

# 

# Módulo	Descrição

# Avaliação das áreas da vida	Registra notas para organização, saúde, desenvolvimento pessoal, finanças e metas pessoais.

# Banco de dados local	Armazena avaliações em SQLite (evolucao\_pessoal.db).

# Exportação CSV	Gera avaliacoes.csv com os dados registrados.

# Interface web com Streamlit	App leve e acessível pelo navegador.

# 🛠️ Tecnologias

# Python 3.x

# Streamlit — interface web

# SQLite — banco de dados local

# Pandas — manipulação de dados

# CSV — exportação de registros

# 🚀 Como rodar localmente

# 1\. Clone o repositório

# bash

# 

# 

# git clone https://github.com/kluskatech-ai/life-tracker-app.git

# cd life-tracker-app

# 2\. Crie e ative um ambiente virtual (recomendado)

# bash

# 

# 

# python -m venv venv

# 

# \# Windows

# venv\\Scripts\\activate

# 

# \# macOS/Linux

# source venv/bin/activate

# 3\. Instale as dependências

# bash

# 

# 

# pip install -r requirements.txt

# Se o arquivo requirements.txt ainda não existir, instale manualmente:

# 

# bash

# 

# 

# pip install streamlit pandas

# 4\. Execute o app

# bash

# 

# 

# streamlit run app.py

# O navegador abrirá automaticamente em http://localhost:8501.
